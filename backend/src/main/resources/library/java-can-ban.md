# Java căn bản: từ biến đến lập trình hướng đối tượng

Tài liệu mẫu do Knowledge Hub biên soạn để minh họa chức năng thư viện.

## 1. Chương trình đầu tiên
```java
public class Hello {
    public static void main(String[] args) {
        System.out.println("Xin chào, Knowledge Hub! 👋");
    }
}
```
Lưu thành Hello.java, chạy javac Hello.java rồi java Hello.

## 2. Biến và điều kiện
Dùng int cho số nguyên, double cho số thực và String cho chuỗi. Đặt tên thể hiện ý nghĩa của dữ liệu.

## 3. Tách trách nhiệm
Một phương thức nên làm một công việc. Truyền dữ liệu qua tham số và trả kết quả thay vì thay đổi trạng thái toàn cục.

## 4. Bài tập
Viết lớp Book có tiêu đề và tác giả. Tạo danh sách ba cuốn sách, in tiêu đề và tìm sách theo từ khóa không phân biệt hoa thường.
