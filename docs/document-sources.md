# Nguồn các tài liệu lấy từ internet

Các file dưới đây được đưa vào thư viện bằng `scripts/import_web_documents.py`, giữ nguyên bản gốc.
Mô tả của từng tài liệu trên web cũng ghi nguồn và giấy phép.

| Loại | File | Tác giả / Nguồn | Giấy phép |
|---|---|---|---|
| PPTX | `KITE-OpenCL-course.pptx` | Simon McIntosh-Smith, Tom Deakin (University of Bristol) — [HandsOnOpenCL Lecture Slides](https://github.com/HandsOnOpenCL/Lecture-Slides) | CC BY 3.0 |
| DOCX | `POGIL.docx` | Calvin University — [CS 108, Fall 2024](https://cs.calvin.edu/courses/cs/108/24fa/) | CC BY-NC-SA 4.0 |
| ZIP | `python-3.14-docs-text.zip` | Python Software Foundation — [docs.python.org](https://docs.python.org/3.14/download.html) | PSF License |
| PDF | `MIT6_0001F16_Lec1.pdf` | Ana Bell, Eric Grimson, John Guttag — [MIT OpenCourseWare 6.0001](https://ocw.mit.edu/courses/6-0001-introduction-to-computer-science-and-programming-in-python-fall-2016/) | CC BY-NC-SA 4.0 |

Giấy phép NC (phi thương mại) chỉ cho phép dùng trong dự án học tập, không dùng cho mục đích thương mại.
